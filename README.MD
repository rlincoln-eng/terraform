# terraform
Repositório destinado a estudos sobre Terraform.

## O que é Docker?
Terraform é uma ferramenta de infraestrutura via código (IaC). Com ela é possível automatizar a provisão e gerenciamento de recursos em nuvem como instancias, espaços de armazenamento, configuração de VPCs, entre outras utilidades.

- [Documentação oficial](https://developer.hashicorp.com/hcp/docs)

## Contextos de Uso / Provedor ou Cenário
Os diretórios desta secção estão organizados por contexto de utilização ou provedor de utilização. Exemplo: "Configuração inicial de 2 instancias EC2 + 1 Configuração de um serviço S3.
