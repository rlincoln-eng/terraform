 # 🛠️ Comandos básico para utilização do Terraform #

## Exeução de script Terraform ##

### Comando para inicializar Terraform ###
terraform init

### Comando para visualizar o que será aplicado na execução do script Terraform ###
terraform plan

### Comando para aplicar plano de execução ###
terraform appy

### Comando para destriuir o que foi criado neste plano de execução ###
terraform destroy
